# TikTokライブ分析 (tiktok-live-stats)

TikTok LIVE の配信中に起きたことを記録し、**リスナー一人ひとりの履歴**を
パソコンの中に永続的に残すための Windows デスクトップアプリです。

TikTok 公式の LIVE 分析は集計値中心で保持期間も約60日、しかも
**リスナー個人単位の履歴が一切残りません**。このツールはその欠損をローカル
データベースで埋めます。

> **非公式ツールです。** TikTok / ByteDance とは一切関係がありません。
> TikTok の非公開プロトコルを解析して動作しており、利用規約に抵触する可能性が
> あります。自己責任でご利用ください。

---

## できること

| 機能 | 内容 |
|---|---|
| 来店記録 | 誰が何回来たか、初回・最終来店日、連続来店 |
| コメント履歴 | 全文を永続保存、全文検索 |
| いいね | 今回 / 前回 / 累計（リスナー単位） |
| ギフト | 種類別・ダイヤ換算、**ハートミー(Heart Me)** の受領数 |
| 入室アラート | 常連・VIP・初見さんの来店を、よみがな・前回来店日・メモ付きで通知 |
| コメント見逃し防止 | 初見の初コメント／VIP発言／未回答の質問をピン留め |
| 配信分析 | 同接推移、新規/リピーター比、エンゲージメント・ファネル、前回比較 |
| 常連チャーンアラート | 「〇〇さんがいつものペースより来ていません」 |
| 貢献度スコア | 来店・コメント・いいね・ギフトを重み付けし VIP を自動判定 |
| 時間帯 × 曜日 | 自分のゴールデンタイムを実データから発見 |
| 報酬ミッション HUD | 配信時間・新規フォロワー等の達成状況（しきい値は設定ファイルで変更可） |
| 書き出し | CSV（リスナー一覧／コメント／ギフト／配信履歴／事務所提出用の月次レポート） |

## 制約（先にお読みください）

1. **過去にさかのぼれません。** TikTok の配信プロトコルには視聴者ごとの累計
   いいね・ギフト・来店履歴が一切流れていません。このアプリが記録した分だけが
   データになります。導入直後の2〜4週間は画面がほぼ空です。

2. **来店回数といいね数は「観測値」です。** TikTok は視聴者が多い配信で入室・
   いいねイベントを間引きます。実際の数より少なく出ることがあります。
   UI 上でも ⓘ マークで明示しています。

3. **外部の署名サーバー(Euler Stream)を経由します。** 無料アカウントを作って
   APIキーを設定すると 1日2,500回まで接続できます（未設定は1日100回）。
   このアプリを他人に渡す場合、**キーは各自で取得**してもらってください。

4. **未署名です。** 初回起動時に Windows SmartScreen の警告が出ます。
   「詳細情報」→「実行」で起動できます。

## 使い方

1. インストーラを実行（または portable 版をそのまま起動）
2. 「接続」画面で自分の TikTok ユーザー名を入力
3. 「配信を記録」を押す（配信前なら「配信が始まるまで待機する」をオン）
4. 配信中は「ライブ」画面、終了後は「配信履歴」「分析」画面

データの保存先は「設定」→「フォルダを開く」から確認できます。
バックアップは同じ画面の「バックアップを書き出す」で 1ファイルに出力されます。

## ソースからビルドする

必要なもの: **Node.js 22.12 以降**（24.x 推奨）、Windows 10/11 x64。
Visual Studio や Python などのビルドツールは **不要** です
（SQLite は Node 組み込みの `node:sqlite` を使用しています）。

```bash
npm ci
npm run build:win
```

`release/<version>/` に NSIS インストーラとポータブル exe が生成されます。

開発時:

```bash
npm run dev          # ホットリロード付きで起動
npm test             # 単体・結合テスト
npm run typecheck
```

### 実配信に対するフィールドダンプ（開発者向け）

TikTok の protobuf は予告なく変わります。ライブラリを更新したら、実際の配信に
対してフィールド名を再確認してください。

```bash
node scripts/dump-fields.mjs <ユーザー名> --minutes 20
```

`captures/` に NDJSON と Markdown レポートが出力されます。レポートには
タイムスタンプの単位、同接フィールドの候補、入室イベントの重複率、
そして **ハートミーの実際の giftId** が含まれます。

## 構成

```
main プロセス        ウィンドウ / ダイアログ / worker のライフサイクル（薄い）
  └ utilityProcess   TikTok 接続 + SQLite + 集計（ESM・ここが本体）
       └ MessagePort renderer へ 2Hz で差分を直接送信（main を経由しない）
renderer             React（sandbox / contextIsolation 有効、Node 参照なし）
```

TikTok に触れるコードは `src/worker/tiktok/` の2ファイルだけに隔離されています。
ライブラリを差し替える場合もそこだけの変更で済みます。

SQL は `src/worker/store/` 配下にのみ存在します。

## ライセンス

**AGPL-3.0-only**。TikTok LIVE への接続に AGPL-3.0 のライブラリ
(tiktok-live-connector / tiktok-live-proto) をバンドルしているため、
アプリ全体が AGPL-3.0 になります。

再配布するときは、同じ条件で配布し、対応するソースコードも入手できるように
してください。詳細は [SOURCE-OFFER.txt](SOURCE-OFFER.txt) を参照。
